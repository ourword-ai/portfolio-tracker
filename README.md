# Portfolio Tracker · 可定制投资组合仪表盘

一个**任何人都能定制自己组合**的单文件投资观察仪表盘。编辑你的持仓、观察列表和目标，数据保存在本地浏览器。加密价格实时刷新。

🔗 **在线使用**：https://ourword-ai.github.io/portfolio-tracker/

---

## 特点

- **完全可定制**：点击「✎ 编辑组合」，增删改你自己的持仓、观察列表、目标金额。
- **本地保存**：数据存在你的浏览器（localStorage），下次打开自动载入。无需注册、无需账号、不上传服务器。
- **加密实时**：BTC / SOL 通过 Binance 公开 API 每 60 秒自动刷新。
- **占比视角**：展示组合构成（加密 / 股票 / 现金占比）与最大持仓集中度，自动提示过度集中风险。
- **示例起步**：首次打开载入一个示例组合，可一键清空重填你自己的。

## 使用方法

1. 打开页面，看到示例组合。
2. 点击右上角 **✎ 编辑组合**。
3. 修改目标金额、增删持仓和观察标的（填代码、名称、占比、现价）。
4. 点 **保存组合** —— 数据存入本地浏览器。
5. 想重来？点 **恢复示例** 清空。

## 功能模块

| 模块 | 说明 | 可编辑 |
|---|---|---|
| Portfolio Overview | 持仓数 + 加密/股票/现金构成 | 随持仓自动计算 |
| Concentration | 最大持仓集中度 + 风险提示 | 随持仓自动计算 |
| Holdings | 各持仓现价、涨跌、占比、赔率 | ✅ 增删改 |
| Watchlist | 观察列表：现价/绊线/扣扳机 + 赔率 | ✅ 增删改 |
| Radar / Triggers / Calendar | 市场主题、交易规则、事件日历 | 示例内容（暂固定） |

## 数据说明

- **加密**：Binance API 实时刷新，无需 key。
- **其他标的**：手动填写现价（自行更新）。
- **本地存储**：所有自定义数据仅存于你的浏览器。换设备或清缓存会丢失——这是设计取舍（零后端、零成本、完全私密）。

## 隐私

本工具**不含任何账号系统、不上传任何数据**。你填的组合只存在你自己的浏览器里。作者无法看到、服务器不保存。

## 技术栈

- 纯静态单文件 HTML + 原生 JS（ES5），零构建、零依赖、零后端。
- 设计遵循「碱白系统（Alkaline UI）」：暖灰纸底、低饱和功能色、完整无障碍支持。
